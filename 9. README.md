## 📊 Projects Completed

### Project 1 – Data Cleaning & Visualization

The first project focused on cleaning and understanding the **Titanic dataset**.

#### Key Work:

- Loaded and inspected the Titanic dataset
- Identified missing values
- Handled missing Age values
- Filled missing Embarked values
- Removed the highly incomplete Cabin column
- Checked for duplicate records
- Created visualizations using Matplotlib and Seaborn
- Analyzed survival, gender, passenger class, and age distributions
- Created correlation heatmaps and box plots

#### Dataset:

**Titanic Dataset**

- 891 rows
- 12 columns before cleaning
- 177 missing Age values
- 687 missing Cabin values
- 2 missing Embarked values

#### Tools Used:

`Python` · `Pandas` · `Matplotlib` · `Seaborn`

#### Outcome:

Developed practical understanding of data preprocessing, missing-value handling, visualization, and communicating patterns through data.

### Project 2 – Predictive Modeling Using Machine Learning

The second project focused on building a **Decision Tree classification model** using the Titanic dataset.

#### Key Work:

- Prepared the dataset for machine learning
- Selected relevant features
- Encoded the categorical Sex variable
- Created training and testing datasets
- Applied an 80:20 train-test split
- Used `random_state=42`
- Trained a Decision Tree Classifier
- Generated predictions
- Evaluated the model using accuracy and a confusion matrix

#### Features Used:

- Pclass
- Sex
- Age
- Fare

#### Target:

`Survived`

#### Model:

`DecisionTreeClassifier`

#### Result:

**Accuracy: 73.74%**

#### Tools Used:

`Python` · `Pandas` · `Scikit-learn` · `Matplotlib`

#### Outcome:

Gained practical experience in supervised machine learning, classification, train-test splitting, prediction, and model evaluation.
